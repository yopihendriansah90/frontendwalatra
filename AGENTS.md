# Aturan UI Mobile

Saat membuat atau mengubah UI website ini, implementasikan navigasi mobile dan desktop secara terpisah sesuai kebiasaan tiap platform.

## Mobile

- Sediakan bottom navigation bar untuk navigasi utama.
- Letakkan menu sekunder di dalam drawer.
- Sediakan tombol hamburger untuk membuka drawer.
- Hilangkan tombol hamburger khusus yang hanya membuka menu kategori.
- Sembunyikan footer pada tampilan mobile.

## Desktop

- Pertahankan alur navigasi dan tampilan desktop yang sudah ada; jangan ubah desktop saat menerapkan aturan mobile ini.
- Jangan tampilkan bottom navigation bar atau tata letak khusus mobile pada desktop.

Pastikan setiap pola hanya tampil pada breakpoint platform yang sesuai. Gunakan aturan yang sama pada halaman dan komponen baru agar navigasi tetap konsisten.
