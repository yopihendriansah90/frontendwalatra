Apa Itu Pull Up?

Pull up adalah olahraga yang bertujuan untuk membentuk otot bagian atas dan menggunakan tubuh sebagai bebannya atau disebut resistance training. Gerakan ini bisa dilakukan oleh semua kalangan jenis kelamin dan usia, hanya saja tingkat kesulitannya yang berbeda-beda.

Tingkat kesulitan yang dimaksud adalah pull up yang menggunakan tubuh sendiri sebagai beban, kesulitannya akan berbeda-beda karena berat dan ukuran tubuh masing-masing orang juga berbeda. Kamu bisa melakukan gerakan ini dimana saja, namun pastikan tumpuan untuk melakukan pull up benar-benar kuat. 

Manfaat Pull Up untuk Tubuh

Seperti yang sudah dikatakan sebelumnya, manfaat latihan pull up sangat beragam. Kamu bisa merasakan dampak dari latihan ini jika dilakukan secara rutin dan gerakannya tepat. Berikut beberapa manfaat yang akan kamu dapatkan dari gerakan pull up:

1. Memperkuat Otot Bagian Atas Tubuh

Hampir sama dengan gerakan back up, gerakan pull up ini berfokus untuk memperkuat otot bagian atas tubuh, seperti lengan, bahu, dan punggung. Selain memperkuat, otot kamu juga akan membesar jika melakukan gerakan ini dengan tepat. 

2. Mempertahankan Berat Badan

Manfaat gerakan pull up lainnya adalah dapat mempertahankan berat badan kamu yang ideal. Gerakan yang bisa dibilang lumayan berat ini dapat meningkatkan metabolisme tubuh sehingga dapat memperpanjang proses pembakaran lemak dalam tubuh yang lebih maksimal. Agar berat badan tetap ideal, kamu bisaa kontrol menggunakan Kalkulator BMI.

3. Melatih Kekuatan Genggaman

Dengan menggunakan berat badan sebagai beban, kamu akan ditantang untung menahan berat badan kamu sendiri hanya dengan kekuatan lengan dan genggaman. Banyak orang yang genggamannya lemah kesulitan melakukan gerakan ini karena selalu lepas ketika ingin mengangkat tubuh. 

4. Meningkatkan Kesehatan Fisik

Sebuah penelitian mengungkapkan bahwa salah satu manfaat pull up adalah dapat meningkatkan kebugaran dan kesehatan tubuh secara menyeluruh. Apabila kamu rutin melakukan gerakan pull up, kamu secara langsung akan mendukung kesehatan tulang, mengurangi nyeri punggung, hingga meningkatkan kesehatan jantung.

5. Menjaga Kesehatan Mental

Menariknya adalah gerakan pull up tidak hanya bisa membantu menjaga kesehatan fisik, tapi juga menjaga kesehatan mental seseorang. Latihan fisik seperti pull up akan melepaskan hormon endorfin yang positif untuk memperbaiki suasana hati dan meningkatkan fungsi kognitif.

Manfaat Pull Up untuk Wanita

Gerakan pull up bisa dilakukan oleh semua jenis kelamin baik pria maupun wanita. Tapi banyak yang berpendapat bahwa wanita akan lebih kesulitan untuk melakukan gerakan ini. Inilah sebabnya pull up lebih identik dengan gerakan olahraga pria. 

Meskipun begitu, tidak menutup kemungkinan untuk wanita bisa melakukannya. Saat ini banyak sekali wanita yang terbukti bisa melakukan pull up dengan jumlah yang banyak. Mereka mengungkapkan bahwa memiliki tujuan tertentu untuk kebugaran dalam melakukan pull up. 

Tidak hanya ke pria, ternyata manfaat pull up untuk wanita juga lumayan banyak. Mulai dari manfaat kebugaran dan kesehatan bisa wanita dapatkan ketika sering melakukan gerakan ini. Berikut beberapa manfaat pull up untuk wanita yang harus kamu ketahui:

  • Memperbaiki tubuh bagian atas seperti bahu, payudara, dan lengan.
  • Menguatkan genggaman tangan
  • Mengurangi risiko bungkuk
  • Menambah kekuatan lengan

Tips Agar Gerakan Pull Up untuk Pembentukan Otot

Jika kamu ingin melakukan gerakan pull up, kamu membutuhkan tumpuan seperti pull up bar, biasanya pull up bar berada di gym, lapangan, dan taman bermain. Namun, kamu juga bisa membeli pull up bar di toko online agar bisa melakukannya di rumah. 

Sebelum mulai melakukan pull up, pastikan posisi ketinggian pull up bar sesuai dengan kemampuan kamu. Selain itu, pastikan pull up bar aman digunakan untuk menghindari risiko cedera saat olahraga.

Berikut tips agar gerakan pull up kamu bisa memaksimalkan pembentukan otot:

  • Berdiri tepat di bawah pull up bar dan rentangkan kaki selebar bahu
  • Genggam erat pull bar dengan telapak tangan mengarah ke depan 
  • Pastikan saat sudah menggenggam pull bar dan kaki sudah menggantung
  • Posisikan kedua tangan lebih lebar dari bahu
  • Angkat tubuh dengan kekuatan tangan sampai kepala melewati pull up bar dan dada menyentuh pull up bar
  • Agar lebih seimbang, posisikan kaki ditekuk ke belakang dan membentuk silang
  • Turunkan badan dengan perlahan agar otot tangan bisa lebih stabil dan kuat
  • Ulangi gerakannya terus menerus sesuai dengan repetisi dan set yang telah ditentukan

Ketika melakukan gerakan ini pastikan untuk tidak terburu-buru. Prioritaskan kualitas gerakan dibanding kuantitas gerakan yang kamu lakukan agar hasil dari gerakan pull up lebih maksimal dan kamu akan mendapatkan manfaat pull up.
