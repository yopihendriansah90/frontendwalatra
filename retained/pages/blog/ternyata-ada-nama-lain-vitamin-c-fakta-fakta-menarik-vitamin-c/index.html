Ternyata Ada Nama Lain Vitamin C! – Fakta-Fakta Menarik Vitamin C

Ditinjau oleh Tim Kesehatan Natural Farm • Ditulis oleh Erwin • 21 Januari 2024

Bagikan:

Vitamin C bisa dibilang sebagai Vitamin yang paling populer dikalangan masyarakat luas. Fungsi dan sumber makanan yang mengandung Vitamin ini sudah dikenal luas bahkan digunakan untuk diet sehat banyak orang. Namun, banyak fakta menarik dari Vitamin C yang tidak banyak orang ketahui. Misalnya, nama lain vitamin c, fungsinya selain meningkatkan imun tubuh, dan lain sebagainya.

Disini, Anda akan mempelajari lebih jauh mengenai fakta-fakta menarik dari Vitamin yang identik dengan warna oranye atau kuning ini. Dan, mungkin Anda bisa mendapatkan inspirasi sehat yang bisa meningkatkan kualitas hidup Anda. Langsung saja kita lihat!

Nama Lain Vitamin C

Vitamin C juga dikenal dengan sebutan Asam Askorbat. Vitamin ini adalah salah satu jenis Vitamin yang mudah larut dalam air. Oleh karena itu, Vitamin C banyak dikonsumsi dalam bentuk minuman, karena lebih mudah diserap oleh tubuh.

  • Mudah Rusak Oleh Panas

Vitamin C ternyata juga mudah rusak karena panas. Panas akan mempercepat proses oksidasi atau pembusukan. Jadi, bahan makanan yang mengandung Vitamin C sebaiknya tidak diproses dengan cara dipanaskan. Hal ini akan menghilangkan Vitamin ini dari makanan tersebut dan Anda hanya mengkonsumsi ampasnya saja.

  • Baik Untuk Penderita Darah Tinggi

Fungsi ini tidak diketahui oleh banyak orang, seperti halnya nama lain vitamin c. Ternyata, Vitamin C juga dapat meningkatkan kesehatan pembuluh darah. Bagaimana prosesnya?

Vitamin C yang mudah larut dalam air juga bersifat diuretik. Sifat ini membantu ginjal untuk mengeluarkan banyak air. Alhasil, dinding pembuluh darah menjadi lebih lemas dan fleksibel. Hal ini akan dapat membantu menurunkan tekanan darah Anda.

  • Meningkatkan Kesehatan Tulang

Salah satu fungsi utama Vitamin C adalah membantu tubuh untuk memproduksi kolagen. Zat kolagen ini dibutuhkan tubuh untuk memperbaiki dan meningkatkan kesehatan tulang dan gigi. Dengan mengkonsumsi Vitamin C sebanyak 75-90 mikrogram per harinya, Anda akan memiliki tulang dan gigi yang sehat.

Sumber Vitamin C

Salah satu cara paling mudah dan populer untuk mendapatkan asupan Vitamin C yang cukup adalah dengan mengkonsumsi suplemen. Banyak orang bahkan lebih suka menggunakan cara ini untuk kebutuhan Vitamin C mereka. Akan tetapi, mengkonsumsi suplemen Vitamin C berlebihan tidaklah baik, karena dapat meningkatkan resiko penyakit batu ginjal.

Cara terbaik adalah dengan mendapatkan Vitamin C dari sumber alaminya, yaitu makanan, seperti sayur dan buah. Buah-buahan seperti, jeruk, kiwi, melon, jambu biji, blackcurrant, stroberi, pepaya, leci dan lemon bisa menjadi sumber terbaik dan sehat Vitamin C harian Anda. Sedangkan untuk sayur, Anda bisa mengkonsumsi brokoli, kembang kol, kangkung, bayam, tomat, dan paprika.

Penutup

Itu dia beberapa fakta menarik mengenai Vitamin C. Sekarang, Anda tidak hanya tahu nama lain vitamin c. Anda juga tahu banyak manfaat dan fungsi kesehatan Vitamin ini.
